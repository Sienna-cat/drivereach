# 项目与作品集的关系

用二手车卖车线索展示文本对话、字段证据、拒联、坐席接管和回拨。购车主案例与卖车演示的业务字段不同；企微承接是方案层内容，未连真实线路或企微。

本项目为个人作品集原型，借助 AI 编码实现。默认使用确定性规则与模拟数据；不能据此声称已部署大模型 Agent、产生真实转化收益或完成企业系统接入。
