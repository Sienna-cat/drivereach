# DriveReach：卖车咨询与人工协同

面向二手车首次咨询，确认车辆信息、出售意愿与接续方式。本人完成产品定义、页面与状态设计、规则实现、持久化及逐案例评测。

关键判断：区分字段已处理和事实已知；近似值继续确认；转接以坐席接受为成功；无空闲坐席时经客户同意创建回拨；拒联取消后续任务。
